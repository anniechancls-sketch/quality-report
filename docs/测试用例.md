## 一、测试依据与范围

### 1.1 依据

1. 《需求文档》——口径定义、指标公式、验收标准
2. 《详细操作流程》——13 步操作预期结果
3. 《完整交互逻辑》——页面状态、分支规则、提示文案、边界清单
4. 附件《质量数据分析与报告生成项目.docx》——452 条原始记录与 7 张附表

### 1.2 范围

覆盖七个模块：数据导入与校验、判定与口径计算、分析总览、周间对比、AI 解读、报告导出、边界与异常。不含本期明确不做项（权限、数据库、系统对接、移动端）。

### 1.3 优先级定义

| 级别 | 含义 | 判定 |
| --- | --- | --- |
| P0 | 阻塞级。算错、口径错、导出失败、断网不可用 | 不通过则不允许演示 |
| P1 | 重要级。状态提示、分支规则、交互反馈不符合预期 | 不通过需修复后再演示 |
| P2 | 体验级。文案、样式、次要交互 | 可带入下一版 |

## 七、测试数据准备

1. **基准数据集**：7 个脱敏 Excel，行数 77/62/58/67/82/90/16，用于全部 P0 用例。
