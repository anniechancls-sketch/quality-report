## 一、项目背景与目标

### 1.1 背景

现场巡检数据由巡检员采集并以 Excel 记录，数据本身已具备结构化基础。但周与周之间的波动、合格率差异和质量变化趋势，目前仍依赖人工整理：拉数据、算合格率、比对差异、写说明，一轮下来耗时且前后口径容易不一致。

本次培训希望在真实脱敏数据上搭建一个轻量工具，验证「程序负责数值计算 + 大模型负责文字归纳」这条路径能否把上述人工工作自动化。

### 1.2 目标

1. 上传脱敏 Excel 后，自动完成数据校验、判定复算、周度指标计算与周间对比。
2. 由 AI 完成周度差异的文字解读与报告正文生成，数值一律来自程序计算。
3. 一键导出 Word、Excel、PDF 三种格式报告，可直接用于培训展示与后续汇报。
4. 用真实数据暴露「口径不一致会导出错误结论」这一风险，使工具本身成为培训案例。

### 1.3 衡量成功的标准

- 从上传数据到导出报告，全流程 3 分钟内完成（不含 AI 等待时间）。
- 判定复算与现场人工判定的一致率为 100%。
- 报告中每一个数值都能追溯到原始数据行。
- 断开网络的条件下，报告仍可正常生成。

### 2.1 本期做

- 多文件 Excel 上传与手动列映射

- 移动端适配

## 三、关键概念与口径定义

本节是全文档的口径基准，任何结论都必须能对应到这里的某一条定义。

| 概念 | 定义 |
| --- | --- |
| 抽检记录 | 一行数据，对应一个箱/扎序号的检测记录，是合格率计算的分母单位 |
| 当期口径 | 使用该周次表头标注的限值复算判定，等价于还原现场当时的判定结果 |
| 统一口径 | 使用统一基准限值对全部周次复算判定，消除标准变化影响，用于周间可比 |
| 统一基准 | 默认取最新标准（外径 31.46–32.02、最小壁厚 ≥1.78、最大壁厚 ≤2.11），四项限值均可在界面修改 |
| 记录级异常 | 一条记录只要存在任一指标超限，即计为 1 条异常记录，用于合格率与异常率 |
| 指标级异常 | 按涉及的指标项分别累计，一条记录可贡献多项，用于异常类型分布与帕累托 |
| 合格率 | 合格记录数 ÷ 抽检记录数 |
| 标准变化影响量 | 同一周次「当期口径合格率 − 统一口径合格率」，用于量化标准变化带来的结论差异 |
| 有效变化 | 两个周次在统一口径下的合格率置信区间不重叠，判定为真实变化 |
| 抽样波动范围内 | 两个周次在统一口径下的合格率置信区间重叠，不构成有效变化，报告中不得表述为上升或下降 |
| 小样本周 | 抽检记录数少于 30 的周次，强制标注「样本量不足，结论仅供参考」 |

### 3.1 判断规则的可复现性验证

需求阶段已用附件 7 周共 452 条明细做过一次完整核对：按各周表头限值复算外径与壁厚判定，与现场人工判定逐条一致，差异 0 条。

这条验证结果决定了整个产品的分工原则：判定与计算完全可以交给程序，AI 不需要接触任何数值。它同时也是「判定复算一致率」这一数据质量指标的基线，一旦上线后该指标低于 100%，说明数据源或映射规则出了问题。

## 四、数据说明

### 4.1 数据来源与结构

现有 7 周脱敏巡检数据，每周一份表格，每份记录一条生产线一天的抽检情况。

| 周次 | 生产日期 | 星期 | 抽检记录数 |
| --- | --- | --- | --- |
| 1周 | 2026/3/12 | 周四 | 77 |
| 2周 | 2026/3/19 | 周四 | 62 |
| 3周 | 2026/3/26 | 周四 | 58 |
| 4周 | 2026/4/2 | 周四 | 67 |
| 5周 | 2026/4/9 | 周四 | 82 |
| 6周 | 2026/4/16 | 周四 | 90 |
| 7周 | 2026/4/23 | 周四 | 16 |
| 合计 | | | 452 |

7 个日期全部为周四且间隔整 7 天，属于按周固定抽检一天的样本。因此所有合格率均表述为「抽检样本合格率」，不代表该周全量生产水平。

### 4.2 字段与已知差异

主要字段：生产日期、箱/扎序号、平均外径、最小壁厚、最大壁厚、测量工具（π尺 / 卡尺）、判定结果、备注。

已识别三处不一致，导入模块必须能容忍：

1. 列数不同：1周表为 5 列，没有「测量工具」和「备注」列；2–7周为 8 列。
2. 限值位置不同：限值写在表头文字里，如「平均外径 要求:31.54-31.94」，不是独立字段，需要人工在界面输入。
3. 限值本身随周次变化，详见 4.3。

### 4.3 限值变化

| 周次 | 平均外径要求 | 最小壁厚要求 | 最大壁厚要求 |
| --- | --- | --- | --- |
| 1周 | 31.54–31.94 | ≥1.78 | ≤2.11 |
| 2–4周 | 31.54–31.94 | ≥1.77 | ≤2.10 |
| 5–7周 | 31.46–32.02 | ≥1.78 | ≤2.11 |

经业务确认，该差异来源为同一规格下的判定标准中途调整，而非不同产品规格。

这意味着直接用各周自己的限值算出的合格率做周间对比，结果中会混入标准变化的贡献。实测数据显示，5–7周合格率明显抬升（96.3% / 92.2% / 93.8%），与第 5 周外径限值放宽同期发生。如果不做口径剥离，AI 会把这个趋势解读为「质量改善」，这是一个错误结论。

### 4.4 两种统一基准的实测对比

需求阶段对两种候选基准都做了重算。判定翻转指与当期口径相比结论发生改变的记录数。

| 周次 | 抽检数 | 当期口径 | 统一到最新标准 | 统一到复合最严标准 |
| --- | --- | --- | --- | --- |
| 1周 | 77 | 76.6% | 83.1% | 74.0% |
| 2周 | 62 | 87.1% | 88.7% | 87.1% |
| 3周 | 58 | 75.9% | 84.5% | 75.9% |
| 4周 | 67 | 83.6% | 88.1% | 83.6% |
| 5周 | 82 | 96.3% | 96.3% | 28.0% |
| 6周 | 90 | 92.2% | 92.2% | 63.3% |
| 7周 | 16 | 93.8% | 93.8% | 62.5% |
| 判定翻转合计 | | | 14 条 | 89 条 |

复合最严标准指外径 31.54–31.94、最小壁厚 ≥1.78、最大壁厚 ≤2.10 这一由不同周次参数拼合而成的标准。它在现实中从未存在过，却会让 5–7周合格率从 96%/92%/94% 跌至 28%/63%/63%，翻转 89 条记录，向质量人员传递「近期质量大幅恶化」的错误信号。

结论：统一基准默认采用最新标准，四项限值做成可配置项；复合最严标准仅作为演示用的对照口径保留，不得作为默认基准。

### 4.5 抽样波动与有效变化判定

按当期口径计算的合格率 95% 置信区间（Wilson 区间）：

| 周次 | 抽检数 | 合格率 | 95% 置信区间 | 区间宽度 |
| --- | --- | --- | --- | --- |
| 1周 | 77 | 76.6% | 66.0% – 84.7% | 18.6pp |
| 2周 | 62 | 87.1% | 76.6% – 93.3% | 16.8pp |
| 3周 | 58 | 75.9% | 63.5% – 85.0% | 21.6pp |
| 4周 | 67 | 83.6% | 72.9% – 90.6% | 17.6pp |
| 5周 | 82 | 96.3% | 89.8% – 98.7% | 9.0pp |
| 6周 | 90 | 92.2% | 84.8% – 96.2% | 11.4pp |
| 7周 | 16 | 93.8% | 71.7% – 98.9% | 27.2pp |

两个关键读法：

- 3周（75.9%）与 5周（96.3%）区间不重叠，是真实变化。
- 2周（87.1%）与 4周（83.6%）、5周（96.3%）与 6周（92.2%）区间大幅重叠，差异落在抽样波动范围内，不构成有效变化。

如果不引入这一判定，AI 会把每周的正常上下浮动都写成质量波动，报告将失去可信度。因此有效变化判定是 AI 解读的前置硬约束，不是可选优化。

### 4.6 异常构成

452 条记录中，合格 390 条，异常 62 条。

| 异常类型 | 记录级计数 | 指标级计数 |
| --- | --- | --- |
| 外径偏大 | 29 | 30 |
| 外径偏小 | 22 | 22 |
| 壁厚偏厚 | 9 | 10 |
| 壁厚偏大 | 1 | 1 |
| 外径偏大 / 壁厚偏厚（组合） | 1 | 该条分别计入外径偏大与壁厚偏厚 |
| 合计 | 62 | 63 |

壁厚偏薄在本期数据中出现 0 次，但分类必须保留，规则上能够识别。

这组数据是双口径计数规则的最佳示例：记录级 62 条，指标级 63 项。若只保留单一口径，报告读者极易把「异常项数」误读为「异常记录数」。

### 4.7 备注与处置信息

2–7周表含备注列，共 44 条非空备注，恰好对应 2–7周的 44 条异常；1周表无备注列，其 18 条异常没有处置记录。

按关键词归类，一条备注可命中多个标签：

| 处置类型 | 备注条数 | 原始文案示例 |
| --- | --- | --- |
| 已反馈班组追溯 | 31 | 已反馈班组追溯 |
| 追溯后合格 | 4 | 往前追溯50公分左右合格 |
| 追溯报废 | 11 | 追溯报废91.5米 / 往前追溯3米，报废了2米 |

报废数量存在明显的单位混用（米、公分并存），且多数为估计值（含「左右」「约」）。因此报废量一律按原文引用，不做求和；如需汇总，必须先在界面上显式选择换算口径，报告中同时说明换算关系。

## 五、用户与使用场景

### 5.1 用户角色

| 角色 | 说明 | 关键诉求 |
| --- | --- | --- |
| 演示者（培训老师） | 单机操作工具，向学员完整演示流程 | 流程流畅、断网可用、结论好讲 |
| 学员 | 观看演示，理解「程序算数 + AI 写话」的分工 | 看得懂每条结论是怎么来的 |
| 质量部门同事 | 评审报告内容与结论合理性 | 口径清楚、数字可追溯 |

本期为单用户本机运行，不设账号与权限。

### 5.2 核心使用场景

场景一 培训现场完整演示：演示者一次上传 7 个 Excel，完成列映射与限值填写，查看校验结果，浏览分析总览，生成 AI 解读，导出三种格式报告。全程约 15 分钟，控制在 20 人以内的小规模场景。

场景二 现场改口径看结论变化：在侧边栏把统一基准改成复合最严标准，页面上 5–7周合格率当场从 96% 跌至 28%，随后切回最新标准。用于说明口径定义决定结论，这是整个演示最有说服力的一幕。

场景三 单周补传：获得新一周数据后单独上传，与已有周次合并分析，刷新趋势与报告。

## 六、功能需求

### M1 数据导入与列映射

目标：把来源不规范的多个 Excel 转成统一的内部数据表。

输入：用户上传的 1 个或多个 Excel 文件（.xlsx / .xls）。

处理规则：

1. 读取用户选择的 sheet，展示表头与首行数据预览（最多 5 行）。
2. 由用户手动指定列映射：箱/扎序号、平均外径、最小壁厚、最大壁厚、判定列、备注列、生产日期。其中判定列与备注列允许留空。
3. 由用户在界面填写该周的限值：外径下限、外径上限、最小壁厚下限、最大壁厚上限。
4. 由用户确认或修改周次标签，默认按生产日期升序自动建议序号（1周、2周……）。
5. 多个文件依次映射，映射配置在本次会话内可复用（模板不同时才需重新指定）。

输出：统一的内部数据表，字段为 prod_date、week_label、box_no、outer_diameter、min_wall、max_wall、verdict、remark、limits。

异常处理：

- 数值列存在非数值内容：该行标为问题行，不参与计算，进入问题清单。
- 必填列未映射或存在空值：阻止进入下一步，并指出具体行号。
- 判定列缺失：允许继续，全部结果以算法复算为准，并在报告中注明「本期无人工判定可比对」。

验收标准：能成功解析 1周表（5 列）与 2–7周表（8 列）两种结构，解析结果行数与原文一致（77/62/58/67/82/90/16）。

### M2 数据质量校验

目标：在计算之前把数据问题暴露出来，避免带着脏数据出结论。

校验项：

1. 必填字段缺失（外径、最小壁厚、最大壁厚）
2. 数值越界（外径不在合理量程，壁厚为负或异常大）
3. 限值缺失或上下限颠倒
4. 重复记录（同一周次、同一箱/扎序号出现多次）
5. 测量工具与指标不匹配（外径应为 π尺、壁厚应为卡尺）
6. 判定复算一致率：算法判定与人工判定逐条比对，输出不一致清单

输出：校验结论卡片（通过 / 警告 / 阻断）+ 问题行清单（可导出）。

异常处理：存在阻断级问题时，不允许进入分析步骤，但允许用户勾选「忽略并继续」并强制记录在报告的口径说明中。

验收标准：在现有 452 条数据上运行，判定复算一致率显示 100%，问题行清单为空；人工构造一条错误判定后，该行能被准确定位。

### M3 判定规则与口径配置

目标：把限值从代码里剥离出来，做成可配置、可复现的口径。

处理规则：

1. 当期口径：每行数据使用其所属周次表头填写的限值进行判定，作为现场结果的还原。
2. 统一口径：全部周次使用同一组基准限值重新判定，基准值默认取最新标准，可在侧边栏修改。
3. 判定逻辑：
   - 外径：下限 ≤ 外径 ≤ 上限
   - 最小壁厚：最小壁厚 ≥ 壁厚下限
   - 最大壁厚：最大壁厚 ≤ 壁厚上限
   - 三项全部满足判为合格，否则按超限方向归类
4. 一次超限涉及多个指标时，判定文本按「外径偏大/壁厚偏厚」形式合并展示。
5. 口径切换后，全部指标、图表、AI 解读同步重算，不保留上一次结果。

输出：两个判定结果列（当期判定、统一判定），以及每行的超限类型明细。

验收标准：当期口径复算结果与现场人工判定完全一致；统一基准改为复合最严标准后，5周合格记录数应由 79 条变为 23 条（翻转 56 条）。

### M4 指标计算

目标：算出报告和 AI 需要的全部数值，AI 不再自行计算。

指标清单见第八章。要求：

1. 所有指标同时输出当期口径与统一口径两组结果。
2. 每个指标附带样本量。
3. 合格率附 95% 置信区间（Wilson 区间）。
4. 抽检记录数少于 30 的周次打上小样本标签。
5. 计算结果以结构化 JSON 形式留存，作为 AI 解读的唯一数值来源。

验收标准：7 周合格率与置信区间与本文档 4.4、4.5 两张表完全一致。

### M5 周间对比与差异拆解

目标：把「看起来有变化」拆成可解释的三种来源，避免把标准变化和抽样波动当成质量变化。

处理规则，每一项差异拆成三列呈现：

1. 数值变化：两个周次在统一口径下的合格率之差，以及各检测指标的均值差。
2. 标准变化：各周次「当期口径合格率 − 统一口径合格率」，反映该周自身受标准调整的影响量。
3. 抽样波动：两个周次统一口径合格率的置信区间是否重叠。重叠则标注「在抽样波动范围内，不构成有效变化」。

支持两种对比模式：环比（第 N 周与第 N−1 周）与全周次趋势总览。

输出：对比表 + 差异结论标签（有效上升 / 有效下降 / 无有效变化）。

验收标准：3周与5周的对比结论为「有效上升」，2周与4周的对比结论为「无有效变化」。

### M6 AI 解读

目标：把程序算好的数字翻译成质量人员能直接使用的说明文字。

输入：结构化指标 JSON，包含各周指标、双口径结果、置信区间、差异拆解结果、异常构成。

处理规则：

1. 调用 DeepSeek 模型，提示词从 prompts 目录读取，可独立修改。
2. 输出分章节文字：整体趋势、显著变化、异常结构、待核实事项。
3. 硬约束：
   - 不产生任何未出现在输入 JSON 中的数值
   - 不做无依据的根因推断
   - 数据不足时固定输出「数据不足，无法确认原因」
   - 落在抽样波动范围内的差异，不得表述为上升或下降
4. 数字回查：生成后提取文本中的全部数字，与指标表逐项比对，存在无法匹配的数字即判定失败并自动重生成一次，仍失败则降级为模板化文本。
5. 离线兜底：调用失败、超时或未配置密钥时，自动使用模板化文本生成，报告其余部分不受影响。
6. 生成结果允许人工编辑后再导出。

输出：解读正文 + 元信息（模型名、耗时、是否降级、数字回查是否通过）。

验收标准：断网状态下能生成完整报告；人为让模型输出一个错误数字时，数字回查能拦截并触发重生成。

### M7 报告生成与导出

目标：一键产出可直接使用的报告。

输出格式与内容：

- Word：完整正文报告，章节结构见第十章
- Excel：总览指标、周间对比、异常明细、原始明细四个工作表，图表使用 Excel 原生图表
- PDF：由 Word 版转换生成，或由 PDF 库直出，保证一定有产物

处理规则：

1. 导出前可勾选需要包含的章节。
2. 报告头固定包含口径说明，注明当前使用的是当期口径还是统一口径，以及统一基准的具体限值。
3. 小样本周在图表中使用虚线或浅色区分，并在图注中标注。
4. 导出文件命名格式：报告类型_数据范围_生成时间。

验收标准：三种格式均能成功导出且可正常打开；报告中的每个数值均可在附录明细中定位到来源行。

## 七、页面与交互设计

整体为左侧导航、右侧内容区的单页应用形态，五个步骤按线性顺序排列，符合演示时的自然讲解节奏。

### P1 数据导入

元素：文件拖拽区、文件列表、表头与前 5 行预览、列映射选择器、限值输入区（外径上下限、壁厚下限、壁厚上限）、周次标签输入框、开始解析按钮。

- 解析完成：展示校验结论与问题清单

### P2 分析总览

元素：KPI 卡片（当期合格率、统一口径合格率、异常率、抽检样本量合计）、合格率趋势图（含置信区间带）、关键指标趋势图（平均外径、最小壁厚均值、最大壁厚均值）、异常类型帕累托图、小样本提示条。

元素：周次选择器（可多选）、对比模式切换（环比 / 全览）、差异拆解表（数值变化、标准变化、抽样波动三列）、结论标签、异常明细下钻表（含备注原文）。

状态：重叠区间高亮提示「不构成有效变化」；点击明细行可查看该记录全部字段。

### P4 AI 解读

元素：生成按钮、解读正文编辑框、元信息条（模型、耗时、是否降级、数字回查结果）、重新生成按钮。

状态：未生成时展示提示；生成中展示进度；降级时明确提示「本次为模板生成，未经模型处理」。

### P5 报告导出

元素：章节勾选列表、格式选择（Word / Excel / PDF）、导出按钮、产物列表（含生成时间与文件大小）。

状态：导出失败时给出可读的错误原因，不显示堆栈信息。

### 侧边栏 口径配置

元素：口径切换（当期口径 / 统一口径）、统一基准四项限值输入、预设选择（最新标准 / 复合最严标准 / 自定义）、恢复默认按钮。

修改限值后需要点击「应用」才触发重算，避免输入过程中反复计算。

## 八、指标定义与计算规则

| 编号 | 指标 | 计算方式 | 口径 |
| --- | --- | --- | --- |
| 1 | 合格率（当期） | 当期口径合格记录数 ÷ 抽检记录数 | 双 |
| 2 | 合格率（统一） | 统一口径合格记录数 ÷ 抽检记录数 | 统一 |
| 3 | 异常率 | 异常记录数 ÷ 抽检记录数 | 双 |
| 4 | 分项异常率 | 各异常类型的记录级数量 ÷ 抽检记录数 | 双 |
| 5 | 抽检记录数 | 各周有效记录数 | 双 |
| 6 | 平均外径 | 均值、极差（最大值−最小值）、标准差（样本标准差，ddof=1） | 双 |
| 7 | 最小壁厚 | 均值、最小值 | 双 |
| 8 | 最大壁厚 | 均值、最大值 | 双 |
| 9 | 外径超限方向分布 | 外径偏大记录数与偏小记录数 | 双 |
| 10 | 判定复算一致率 | 算法判定与人工判定一致的记录数 ÷ 可比对记录数 | 当期 |
| 11 | 标准变化影响量 | 当期口径合格数 − 统一口径合格数 | 单周 |
| 12 | 异常集中度 | 异常记录数排名前 N 的箱/扎序号占比，N 默认 5 | 双 |
| 13 | 外径过程能力指数 | Cp = (USL − LSL) ÷ (6σ)，Cpk = min(USL − μ, μ − LSL) ÷ (3σ) | 双 |
| 14 | 备注处置分布 | 按关键词归类后的各类条数，报废量按原文引用 | 单周 |

补充公式：

- Wilson 置信区间中心值 = (p̂ + z²/2n) ÷ (1 + z²/n)
- Wilson 置信区间半宽 = z × √(p̂(1−p̂)/n + z²/4n²) ÷ (1 + z²/n)
- 其中 p̂ 为合格率，n 为样本量，z 取 1.96（95% 置信水平）
- Cpk 仅在双边限值指标上计算，壁厚为单边限值，不适用

## 九、AI 解读设计

### 9.1 提示词结构

提示词存放于 prompts 目录，分四段：

1. 角色与任务：质量数据分析助手，把已计算好的指标转写成说明文字
2. 输入数据：结构化指标 JSON
3. 输出格式：整体趋势、显著变化、异常结构、待核实事项四个小节
4. 硬约束：禁止计算与推算、禁止无依据归因、波动范围内不得表述为变化、数据不足必须明说

### 9.2 数值回查

生成完成后执行三步检查：

1. 提取正文中全部数字（含百分数、小数、整数）
2. 与指标 JSON 中的数值集合比对，允许格式差异（如 83.1% 与 0.831）
3. 存在无法匹配的数字即判定失败，自动重生成一次；再次失败则降级为模板文案，并在界面上标明

### 9.3 离线兜底

触发条件：未配置密钥、网络不可达、调用超时（默认 30 秒）、返回格式异常、数字回查连续失败。

兜底行为：使用预置模板，把指标填入固定句式生成解读正文，结构完整、数值取自程序计算，仅缺少模型润色。界面明确标注本次为模板生成。

### 9.4 成本控制

单次解读输入控制在 4000 token 以内，输出控制在 1500 token 以内；仅对选中周次生成解读；重复生成时提示可能产生额外费用。

## 十、报告设计

### 10.1 Word 报告结构

1. 报告头：项目名、覆盖周次、抽检日期、样本量合计、生成时间、口径说明
2. 执行摘要：5 条以内，只写数据支持的结论
3. 关键指标总览：指标表 + 趋势图
4. 周间差异对比：数值变化 / 标准变化 / 抽样波动三列拆开呈现
5. 异常结构分析：异常类型帕累托、各周异常类型堆叠柱、重点异常明细含备注原文
6. 结论与建议：分「数据支持的结论」与「数据不足、待现场核实」两栏
7. 附录 A：判定规则与口径说明
8. 附录 B：各周抽检明细

### 10.2 Excel 报告结构

| 工作表 | 内容 |
| --- | --- |
| 总览指标 | 各周全部指标，当期与统一口径并列 |
| 周间对比 | 差异拆解表与结论标签 |
| 异常明细 | 全部异常记录，含超限类型、备注原文、处置归类 |
| 原始明细 | 导入后的完整数据表，含两个口径的判定结果 |

### 10.3 PDF 报告

由 Word 版转换生成，优先调用本机 Word 或 LibreOffice；检测不到时改用 PDF 库按同一版式直出，保证导出环节一定有产物。

## 十四、风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 现场网络或 API 额度不可用 | 演示中断 | 离线兜底模板生成，演示前断网演练一次 |
| AI 输出错误数字 | 报告不可信 | 数字回查 + 自动重生成 + 降级兜底 |
| 读者误读口径 | 得出错误结论 | 报告头与图表固定标注口径；当期与统一结果分列展示 |
| 小样本周被当成趋势依据 | 结论失真 | 小样本标签、虚线区分、有效变化判定 |
| 报废量单位混用 | 汇总数字错误 | 按原文引用，不自动求和，汇总需显式选择换算口径 |
| PDF 导出依赖本机软件 | 导出失败 | 双路径：优先转换，不行则 PDF 库直出 |
| 新一周数据格式变化 | 导入失败 | 手动列映射，映射配置会话内可复用 |
