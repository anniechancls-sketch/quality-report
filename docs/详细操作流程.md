## 一、前置准备

### 1.1 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 及以上 |
| 运行环境 | Python 3.10 及以上 |
| 浏览器 | Edge 或 Chrome |
| 网络 | 可选。联网时启用 AI 解读，断网时自动走模板生成 |
| 可选软件 | Microsoft Word 或 LibreOffice（用于 PDF 转换，缺失时由 PDF 库直出） |

### 1.2 数据准备

1. 准备 7 个脱敏 Excel 文件，每周一个文件。
2. 文件名建议包含周次与日期，例如 `1周_20260312.xlsx`，便于上传后核对。
3. 确认文件内容已脱敏，不含产品规格、批次等敏感字段。
4. 提前打开任意一份文件，确认表头文字包含「平均外径」「最小壁厚」「最大壁厚」「判定是否合格」，以及是否有「测量工具」「备注」列。

### 1.3 API Key 准备

1. 准备 DeepSeek 的 API Key。
2. 两种提供方式，任选其一：
   - 启动前设置环境变量（推荐，演示时不会被看到）
   - 启动后在界面侧边栏的密钥输入框中填入
3. 不要把 Key 写入任何文件、脚本或聊天记录。
4. 确认账户余额或额度足够完成至少 5 次解读调用（含排练与正式演示）。

### 1.4 启动前检查清单

- [ ] Python 环境可用
- [ ] 依赖已安装
- [ ] 7 个 Excel 文件已就位且可打开
- [ ] API Key 已配置或已知可用
- [ ] 浏览器可用
- [ ] 断网演练已做过一次

## 三、详细步骤

### 步骤 1 启动工具

操作：

1. 打开命令行，进入项目目录。
2. 执行 `streamlit run app/main.py`。
3. 浏览器自动打开工具界面。若未自动打开，复制命令行提示的本地地址到浏览器。

看到什么：左侧为导航与口径配置，右侧默认停在「数据导入」页，页面显示文件拖拽区。

注意：如果提示端口被占用，命令行会给出新的端口号，用新地址打开即可。

### 步骤 2 上传数据文件

操作：

1. 点击拖拽区，或直接把 7 个 Excel 文件拖入。
2. 等待文件列表刷新。

看到什么：文件列表按文件名排列，显示每个文件的大小与状态。

注意：

- 可以分次上传，也可以一次补传单周。
- 若某个文件状态显示为「读取失败」，先确认文件未被其他程序占用，重新上传即可。

### 步骤 3 逐文件完成列映射

操作：

1. 在文件列表中选择一个文件。
2. 核对页面显示的表头与前 5 行预览。
3. 在列映射区依次指定：箱/扎序号、平均外径、最小壁厚、最大壁厚、判定列、备注列、生产日期。

映射参照，以附件数据为例：

| 字段 | 1周表 | 2–7周表 |
| --- | --- | --- |
| 箱/扎序号 | 「箱/扎」列 | 「箱/扎」列 |
| 平均外径 | 「平均外径 要求:…」列 | 「平均外径 要求:…」列 |
| 最小壁厚 | 「最小壁厚 要求:…」列 | 「最小壁厚 要求:…」列 |
| 最大壁厚 | 「最大壁厚 要求:…」列 | 「最大壁厚 要求:…」列 |
| 判定列 | 「判定是否合格」列 | 「判定是否合格」列 |
| 备注列 | 无，留空 | 「备注」列 |
| 生产日期 | 表头标注日期，若无该列则手工输入 | 同左 |

注意这两个容易出错的地方：

- **2–7周表有两个「测量工具」列**，一列属于外径、一列属于壁厚。系统在遇到重复列名时会要求人工确认具体列位置，不要凭列序号猜。
- **1周表结构不同**，没有测量工具与备注列，映射时把这两项留空即可，不要错位选到相邻列。

看到什么：每完成一个文件的映射，页面显示该文件的解析预览与行数。

### 步骤 4 填写该周限值

操作：在映射区下方的限值输入框中填写该文件对应的限值。

各周限值对照表：

| 周次 | 外径下限 | 外径上限 | 最小壁厚下限 | 最大壁厚上限 |
| --- | --- | --- | --- | --- |
| 1周 | 31.54 | 31.94 | 1.78 | 2.11 |
| 2周 | 31.54 | 31.94 | 1.77 | 2.10 |
| 3周 | 31.54 | 31.94 | 1.77 | 2.10 |
| 4周 | 31.54 | 31.94 | 1.77 | 2.10 |
| 5周 | 31.46 | 32.02 | 1.78 | 2.11 |
| 6周 | 31.46 | 32.02 | 1.78 | 2.11 |
| 7周 | 31.46 | 32.02 | 1.78 | 2.11 |

注意：

- 这里填的是**当期口径**限值，即该周现场使用的标准，不是统一基准。
- 填错会导致复算一致率下降，很容易在校验环节被发现，但会浪费时间。
- 上下限填反时，系统会直接阻止继续。

看到什么：限值填写完成后，该文件右侧的解析结果会立即按新限值刷新判定。

### 步骤 5 确认周次标签

操作：检查系统按生产日期自动建议的周次标签，必要时手动修改。

看到什么：文件列表中 7 个文件分别标记为 1周–7周。

注意：标签决定报告里的显示名称和排序，务必与实际周次一致。

### 步骤 6 查看校验结果

操作：7 个文件全部映射完成后，点击进入校验结果。

预期看到：

| 检查项 | 预期结果 |
| --- | --- |
| 解析总行数 | 452 |
| 各周行数 | 77 / 62 / 58 / 67 / 82 / 90 / 16 |
| 判定复算一致率 | 100% |
| 问题行 | 0 条 |
| 小样本周提示 | 7周（16 条）触发 |

若结果不符合预期，按下面顺序排查：

1. 一致率不是 100%：先查该周的限值是否填错，再查最小壁厚与最大壁厚两列是否选反。
2. 出现大量空值：查列映射是否错位，尤其是 2–7周表的两列「测量工具」。
3. 行数偏少：查是否漏传文件，或该文件是否有一行被识别为表头。
4. 出现大量越界值：查是否存在小数点错位，例如把 31.756 读成 31756。

### 步骤 7 阅读分析总览

操作：进入「分析总览」页，逐项阅读。

预期看到的数字（当期口径）：

| 周次 | 抽检数 | 合格率 |
| --- | --- | --- |
| 1周 | 77 | 76.6% |
| 2周 | 62 | 87.1% |
| 3周 | 58 | 75.9% |
| 4周 | 67 | 83.6% |
| 5周 | 82 | 96.3% |
| 6周 | 90 | 92.2% |
| 7周 | 16 | 93.8% |

阅读要点：

1. 合格率曲线上的阴影带是 95% 置信区间，**带子宽度代表这个数字的可信程度**，不是误差范围标注。
2. 7周曲线使用虚线并带小样本提示，不能据此判断趋势。
3. 只看曲线会得出「5–7周明显改善」的结论，这个结论在第 9 步会被推翻，这正是本工具要讲清的重点。
4. 异常类型帕累托图看两点：外径问题是否占主导、异常是否集中在少数箱/扎序号。

### 步骤 8 使用周间对比

操作：

1. 进入「周间对比」页。
2. 选择对比模式：环比或全周次总览。
3. 选择需要对比的周次。
4. 阅读差异拆解表的三列。

如何读三列：

| 列 | 含义 | 怎么用 |
| --- | --- | --- |
| 数值变化 | 统一口径下两周的合格率差与指标均值差 | 看变化幅度 |
| 标准变化 | 该周自身「当期 − 统一」的差 | 看有多少差异是标准调整带来的 |
| 抽样波动 | 两周置信区间是否重叠 | 决定这个变化能不能下结论 |

预期结论：

- 3周与5周：统一口径下判定为「无有效变化」（当期口径下两区间不重叠，但跨周比较以统一口径为准，页面会同时给出两组区间供讲解）。
- 2周与4周：无有效变化，页面标注「在抽样波动范围内」。

操作提示：点击差异表中的任意一行，可下钻到该记录的全部字段与备注原文。

### 步骤 9 切换口径（演示重点）

操作：

1. 打开左侧边栏的「口径配置」。
2. 在预设中选择「复合最严标准」，四项限值自动填充为 31.54 / 31.94 / ≥1.78 / ≤2.10。
3. 点击「应用」。
4. 观察分析总览的合格率变化。

预期变化：

| 周次 | 当期口径 | 切换后 |
| --- | --- | --- |
| 1周 | 76.6% | 74.0% |
| 2周 | 87.1% | 87.1% |
| 3周 | 75.9% | 75.9% |
| 4周 | 83.6% | 83.6% |
| 5周 | 96.3% | 28.0% |
| 6周 | 92.2% | 63.3% |
| 7周 | 93.8% | 62.5% |

讲清这一点：**数据一行没变，只是换了一套判定标准，5–7周的合格率就从 96%/92%/94% 掉到 28%/63%/63%。** 复合最严标准在现实中从未存在过，它只是把不同周次的参数拼在一起，所以它不能当作基准。这正是报告必须同时给出「当期口径」和「统一口径」两个数字的原因。

演示收尾操作：

5. 把预设切回「最新标准」，点击「应用」。
6. 确认合格率恢复为当期数值。

注意：演示前务必练习这一步，口径切换后全部图表与 AI 解读都会重算，若忘了切回会带着错误口径继续演示。

### 步骤 10 生成 AI 解读

操作：

1. 进入「AI 解读」页。
2. 确认当前口径（建议先用当期口径生成一次）。
3. 点击「生成解读」。

看到什么：

- 正文按四个小节生成：整体趋势、显著变化、异常结构、待核实事项。
- 页面上方显示元信息：使用的模型、耗时、是否走了模板兜底、数字回查是否通过。

验收要点：

- 数字回查应显示「通过」。若显示未通过且已自动重生成，观察第二次结果即可。
- 若显示「本次为模板生成」，说明在线调用失败，报告仍可用，但要在演示时说明这是兜底路径。

### 步骤 11 编辑与重新生成

操作：

1. 直接在正文编辑框中修改措辞。
2. 若想重新生成，点击「重新生成」（会提示可能产生额外费用）。

注意：人工编辑过的文字会直接进入报告，系统不再对其中的数字做回查，因此改动数值前要谨慎。

### 步骤 12 导出报告

操作：

1. 进入「报告导出」页。
2. 勾选需要包含的章节（默认全选）。
3. 选择格式：Word、Excel、PDF，可多选。
4. 点击「导出」。

看到什么：产物列表出现对应文件，显示文件名、生成时间、文件大小、保存路径。

注意：PDF 若因为本机没有 Word 或 LibreOffice 而走备用生成路径，文件外观会略有差异，内容不变。

### 步骤 13 核验导出结果

操作：

1. 打开 Word 报告，翻到附录 B「各周抽检明细」。
2. 随机挑一个不合格记录，核对它的外径、最小壁厚、最大壁厚与原始 Excel 是否一致。
3. 回到报告头的口径说明，确认标注的口径与实际使用的基准一致。
4. 打开 Excel 报告，确认四个工作表都存在。

看到什么：所有数值与原始数据一致，无缺行、无错位。

## 四、异常情况处理流程

### 4.1 断网或未配置密钥

现象：AI 解读页提示「已切换为模板生成」。

操作：直接继续，其余步骤不受影响。演示时说明：这是设计好的兜底路径，报告结构完整、数值来自程序计算，只是缺少模型润色。

### 4.2 API 超时或额度不足

现象：解读生成超过 30 秒仍未返回，或提示额度不足。

操作：

1. 等待系统自动降级。
2. 若需再次尝试，检查 Key 与余额后点击「重新生成」。
3. 演示现场不建议现场排查额度问题，直接使用兜底结果继续。

### 4.3 数字回查未通过

现象：元信息显示「数字回查未通过，已重新生成」。

操作：查看第二次结果。若仍提示未通过且已降级，接受模板文案，并在演示中说明系统的数值安全机制生效了。

### 4.4 解析失败或列映射错误

现象：解析预览为空、行数异常、出现大量空值。

操作：

1. 重新打开该文件，确认 sheet 选择正确。
2. 检查数据是否从第一行开始（上方无多余说明行）。
3. 重新指定列映射，重点是两列「测量工具」。
4. 若文件中有合并单元格，先在 Excel 中取消合并再上传。

### 4.5 校验阻断

现象：页面显示阻断级问题，无法进入分析。

操作：

1. 查看问题行清单，定位到具体行号。
2. 修正原始数据后重新上传该周文件。
3. 演示场景下也可勾选「忽略并继续」，系统会把此事强制写入报告的口径说明，避免结论被误解。

### 4.6 PDF 导出失败

现象：产物列表显示 PDF 生成失败。

操作：

1. 先在 Word 报告中另存为 PDF，保证演示有 PDF 可用。
2. 检查本机是否安装 Word 或 LibreOffice，安装后重试。

### 4.7 现场演示中断的应急动作

| 中断原因 | 应急动作 |
| --- | --- |
| 工具崩溃 | 重启工具，已上传数据需重新上传，建议提前准备好映射参数 |
| 浏览器卡死 | 刷新页面，Streamlit 会重开会话 |
| 数据文件被占用 | 关闭打开该文件的 Excel 后重新上传 |
| 时间不够 | 跳过步骤 11、13，直接从步骤 10 跳到步骤 12 导出 |

## 七、常见问题

**Q1 为什么 7周的合格率比 1周高，但报告说不能算是改善？**

因为 7周只有 16 条记录，置信区间宽度约 27 个百分点，与 1周的区间有重叠可能。样本量不足时，合格率的高低不能直接解读为质量好坏。

**Q2 为什么同一批数据有两个合格率？**

当期口径还原现场当时的判定，统一口径用同一套基准重算，后者才可跨周比较。两个数字都必须展示，缺一个都会导致误读。

**Q3 我把限值改错了，会影响已经导出的报告吗？**

不会修改已导出的文件，但重新导出会使用新限值。如果报告已对外发出，需要按正确口径重新导出并说明。

**Q4 备注里的报废米数为什么没有合计？**

报废量本身单位统一是米，但备注里还出现公分，那是追溯距离——两者是不同的物理量，且多为估计值，直接相加会得出错误数字。需要汇总时，先在界面上选择换算口径，报告会同时说明换算关系。

**Q5 能不能跳过列映射？**

不能。本项目明确不做固定模板解析，因为不同产品、不同规格的表格格式可能不同，强制自动识别会带来更高的出错风险。映射配置在会话内可复用，实际重复操作量很小。
