## 一、全局交互规则

### 1.1 页面框架

界面为左侧导航加右侧内容区的单页应用，共五页加一个配置区：

| 编号 | 页面 | 前置条件 |
| --- | --- | --- |
| P1 | 数据导入 | 无 |
| P2 | 分析总览 | 至少一周数据完成映射且校验未阻断 |
| P3 | 周间对比 | 至少两周数据完成解析 |
| P4 | AI 解读 | 指标已计算完成 |
| P5 | 报告导出 | 指标已计算完成 |
| S1 | 口径配置（侧边栏） | 无 |

导航项始终可见。未满足前置条件时该项禁用，鼠标悬停显示禁用原因，不允许跳过后再报错。

不允许跳步执行：未完成 P1 校验时，直接进入 P2 不触发任何计算。

### 1.2 状态保存范围

1. 全部状态保存在会话内，页面刷新即丢失，需重新上传数据。
2. 文件内容不写入磁盘，仅在内存中处理。
3. 导出产物写入 output 目录，属于唯一落盘内容。

### 1.3 计算触发时机

| 用户动作 | 触发的重算范围 |
| --- | --- |
| 上传文件 | 解析该文件，生成预览 |
| 修改某文件的列映射 | 重新解析该文件，刷新其预览与行数 |
| 修改某周的当期限值 | 重算该周当期判定与当期口径指标 |
| 点击「应用」口径配置 | 重算全部周次的统一判定、全部指标、全部图表 |
| 修改小样本阈值 | 仅刷新标签，不重算数值 |
| 修改异常分类词表 | 重算指标级异常与备注归类 |
| 生成 AI 解读 | 使用当前指标结果调用，不重算指标 |

关键规则：口径配置修改后不立即重算，必须点击「应用」。未应用时页面顶部固定显示提示条，同时禁用导出按钮，防止带着未生效的口径导出报告。

### 1.4 按钮启用条件

| 按钮 | 启用条件 | 禁用时的表现 |
| --- | --- | --- |
| 开始解析 | 至少选择 1 个文件 | 置灰，悬停提示需先上传文件 |
| 进入分析 | 全部文件解析完成，且无阻断级问题 | 置灰，悬停提示具体阻断原因 |
| 应用（口径配置） | 存在未应用的修改 | 置灰表示当前无待应用修改 |
| 生成解读 | 指标已计算完成 | 置灰 |
| 重新生成 | 已有解读结果或曾生成失败 | 置灰 |
| 导出 | 指标已计算完成且口径修改已应用 | 置灰，悬停提示未应用的口径修改 |

### 1.5 提示分级

| 级别 | 使用场景 | 表现 |
| --- | --- | --- |
| 提示 | 一般信息，如小样本说明 | 浅色提示条，不阻挡操作 |
| 警告 | 可能影响结论但可继续，如疑似重复文件 | 黄色标记，允许继续但要求确认 |
| 阻断 | 无法继续计算，如限值颠倒 | 红色标记，禁用后续步骤 |

错误提示只显示可读原因，不显示堆栈信息，技术细节写入本地日志。

### 1.6 数字展示规范

| 数据类型 | 展示格式 | 附加要求 |
| --- | --- | --- |
| 合格率 | 保留 1 位小数并带 % | 必须同时显示样本量 |
| 置信区间 | [下限%, 上限%] | 同时显示区间宽度（pp） |
| 外径、壁厚测量值 | 保留 3 位小数 | 与原始数据精度一致 |
| 极差、标准差 | 保留 3 位小数 | 标注样本量 |
| 记录条数 | 整数 | 不做千分位分隔 |
| 小样本周 | 数字后加 * 号 | 图注中说明 * 表示样本量不足 |

## 二、页面元素与交互细则

### P1 数据导入

元素清单：

| 编号 | 元素 | 控件类型 | 默认值 | 约束 |
| --- | --- | --- | --- | --- |
| P1-1 | 文件拖拽区 | 上传控件 | 空 | 支持 .xlsx / .xls，单文件上限 20MB |
| P1-2 | 文件列表 | 列表 | 空 | 每项显示文件名、大小、状态、周次标签 |
| P1-3 | sheet 选择 | 下拉 | 第一个 sheet | 仅当文件含多个 sheet 时显示 |
| P1-4 | 表头与数据预览 | 表格 | 空 | 显示表头与前 5 行 |
| P1-5 | 列映射选择器 | 下拉组 | 未选择 | 7 个字段，其中判定列与备注列可留空 |
| P1-6 | 当期限值输入 | 数字输入 | 空 | 4 项：外径下限、外径上限、最小壁厚下限、最大壁厚上限 |
| P1-7 | 周次标签输入 | 文本框 | 自动建议 | 不允许两周使用同一标签 |
| P1-8 | 生产日期输入 | 日期选择 | 自动识别 | 识别失败时必填 |
| P1-9 | 解析结果预览 | 表格 | 空 | 显示解析后的行数与判定结果 |
| P1-10 | 校验结论卡片 | 卡片 | 空 | 显示通过 / 警告 / 阻断 |
| P1-11 | 问题行清单 | 表格 | 空 | 显示行号、问题类型、原值 |
| P1-12 | 开始解析按钮 | 按钮 | 可用 | 至少 1 个文件时可用 |
| P1-13 | 忽略并继续 | 复选框 | 未勾选 | 仅存在阻断问题时出现 |

字段校验规则：

| 校验项 | 规则 | 失败级别 |
| --- | --- | --- |
| 必填列 | 箱/扎、外径、最小壁厚、最大壁厚必须映射 | 阻断 |
| 限值填写 | 4 项限值均不能为空 | 阻断 |
| 限值方向 | 外径下限必须小于上限；壁厚限值均为正数 | 阻断 |
| 限值合理性 | 外径上下限之差小于 0.01 时 | 警告 |
| 数值可解析 | 数值列内容可转为数值，允许带单位后缀 | 警告，无法解析的行进问题清单 |
| 周次标签唯一 | 两个文件不得使用同一标签 | 阻断 |
| 重复文件 | 文件名与行数均相同 | 警告，要求确认 |

状态与显示条件：

| 状态 | 触发条件 | 页面表现 |
| --- | --- | --- |
| 空态 | 未上传任何文件 | 显示拖拽区与上传说明 |
| 解析中 | 正在读取文件 | 显示进度指示，禁用开始解析按钮 |
| 部分完成 | 部分文件已映射 | 文件列表逐项显示状态 |
| 全部完成 | 全部文件解析通过 | 启用进入分析 |
| 警告态 | 存在警告级问题 | 黄色标记，允许继续 |
| 阻断态 | 存在阻断级问题 | 红色标记，禁用进入分析，显示忽略并继续选项 |

交互规则：

1. 若一个文件含多个 sheet，默认选中第一个，并要求用户确认；用户切换 sheet 后原有映射清空，需重新指定。
2. 列映射下拉中的选项为「列序号 + 表头文字」，避免同名列表头造成的误选。
3. 当同一文件存在多个同名列（如两列「测量工具」）时，系统在下拉中标注列位置，并在用户选择后回显该列前 3 个值供确认。
4. 用户修改任一映射或限值后，该文件的解析预览与校验结论立即失效并重新计算，不做全量重算。
5. 判定列留空时，校验结论卡片中「判定复算一致率」显示为「不适用」，并在报告口径说明中自动追加一句说明。
6. 删除已上传文件时，其周次标签一并释放，可供其他文件使用。
7. 存在阻断问题时，「进入分析」保持禁用；用户勾选「忽略并继续」后按钮可用，但报告的口径说明中会保留该记录。

| P2-4 | 关键指标趋势图 | 折线图 | 空 | 平均外径、最小壁厚均值、最大壁厚均值 |
| P2-5 | 异常类型帕累托图 | 组合图 | 空 | 柱为记录数，折线为累计占比 |

状态与显示条件：

- 某周记录数为 0 时，该周在所有图表中显示为断点，并在图注中标明该周无有效数据。

交互规则：

1. 点击 KPI 卡片可跳转到对应的明细视图。
2. 点击趋势图上的数据点，展示该周全部指标与该周限值。
3. 悬停置信区间带时，显示区间上下限与样本量。
4. 小样本周的合格率数值后固定带 * 号，图注中说明含义。

### P3 周间对比

元素清单：

| 编号 | 元素 | 控件类型 | 默认值 | 约束 |
| --- | --- | --- | --- | --- |
| P3-1 | 对比模式切换 | 单选 | 环比 | 环比 / 全周次总览 |
| P3-2 | 周次选择器 | 多选 | 全部周次 | 全周次总览模式下至少选 2 周 |
| P3-3 | 差异拆解表 | 表格 | 空 | 三列：数值变化、标准变化、抽样波动 |
| P3-4 | 结论标签 | 标签 | 空 | 有效上升 / 有效下降 / 无有效变化 |
| P3-5 | 异常明细下钻表 | 表格 | 空 | 含备注原文与处置归类 |
| P3-6 | 记录详情面板 | 侧栏 | 隐藏 | 点击明细行后展示 |

状态与显示条件：

- 只有一周数据时，本页显示空态，功能不可用。
- 两周置信区间重叠时，结论标签显示「无有效变化」，并附加文字「在抽样波动范围内」。
- 当两周使用的当期限值不同时，差异拆解表中额外显示一行「标准变化提示」，注明限值差异内容。

交互规则：

1. 「数值变化」列固定使用统一口径计算，不受用户当前查看口径影响。
2. 「标准变化」列固定使用各周自身的当期与统一结果之差。
3. 「抽样波动」列的判定结果只有两种：超出波动范围、在波动范围内，不允许出现模糊表述。
4. 环比模式下第 1 周没有前一周，该行显示为「基准周」。
5. 点击异常明细的任意行，展开记录详情，展示该记录全部字段、当期判定、统一判定与备注原文。
6. 异常明细表中的记录数受 P2-8 周次筛选影响，两个页面筛选状态保持同步。

元素清单：

| 编号 | 元素 | 控件类型 | 默认值 | 约束 |
| --- | --- | --- | --- | --- |
| P4-1 | 口径提示 | 文本 | 当前口径 | 生成前固定展示 |
| P4-2 | 生成解读按钮 | 按钮 | 可用 | 指标未计算时禁用 |
| P4-3 | 解读正文编辑框 | 多行文本 | 空 | 生成后可编辑 |
| P4-4 | 元信息条 | 文本 | 空 | 模型名、耗时、是否降级、数字回查结果 |
| P4-5 | 重新生成按钮 | 按钮 | 禁用 | 生成过一次后可用，点击前弹确认 |
| P4-6 | 重置按钮 | 按钮 | 禁用 | 清空当前解读 |

状态与显示条件：

| 状态 | 触发条件 | 页面表现 |
| --- | --- | --- |
| 未生成 | 进入页面但未生成 | 显示说明与生成按钮 |
| 生成中 | 调用进行中 | 显示进度，禁用生成与重新生成 |
| 生成成功 | 模型返回且数字回查通过 | 展示正文与元信息 |

交互规则：

1. 口径配置应用后，已有解读自动失效并清空，不允许沿用手工编辑过的旧文案。
2. 重新生成前弹出确认，提示可能产生额外模型调用费用。
3. 人工编辑过的内容在导出时原样使用，系统不再对编辑后的文字做数字回查，编辑框下方固定显示该提示。
4. 解读正文的四个小节标题固定，不允许模型自行增删小节。
5. 生成失败但已降级时，页面只显示「已使用模板生成」，不显示错误堆栈。

4. 产物列表保留最近 10 条记录，超出部分不自动删除，仅不再显示。

5. API Key 输入框填入后只显示掩码，不回显原文；已通过环境变量配置时该输入框置灰并标注来源。
6. 小样本阈值修改不需要点击应用，立即生效，但只影响标签与图注，不影响任何数值。

## 三、关键交互链路

### 3.1 导入链路

```
上传文件
  ├─ 读取失败 → 标记该文件为失败 → 允许重新上传
  └─ 读取成功
       ├─ 多个 sheet → 要求确认 sheet → 切换则清空映射
       └─ 展示表头预览
            └─ 用户指定列映射（含重复列名确认）
                 └─ 用户填写当期限值
                      ├─ 限值非法 → 阻断 → 应用按钮禁用
                      └─ 限值合法 → 解析并预览
                           └─ 校验
                                ├─ 阻断级 → 禁用进入分析 → 可勾选忽略并继续
                                ├─ 警告级 → 允许继续 → 结论标注
                                └─ 通过 → 启用进入分析
```

规则要点：

1. 每个文件的映射与限值独立保存，互不影响。
2. 解析结果按文件粒度缓存，修改一个文件不触发其他文件重解析。
3. 单个文件失败不阻断其他文件继续处理。

### 3.2 口径切换链路

```
修改侧边栏口径配置
  → 进入「有未应用修改」状态（顶部提示条 + 禁用导出）
  → 点击应用
      → 校验限值合法性
          ├─ 非法 → 阻止并提示，保持未应用状态
          └─ 合法 → 重算全部统一判定 → 重算全部指标 → 刷新图表
                    → 清空 AI 解读 → 清除未应用状态
```

规则要点：

1. 重算只改变判定结果，不修改任何测量值。
2. 当期口径与统一口径两套结果始终同时存在，切换仅改变页面的主展示口径。
3. 重算过程中页面显示加载状态，禁止重复点击应用。

### 3.3 AI 生成链路

```
点击生成解读
  ├─ 未配置密钥 → 直接走模板兜底 → 标注降级原因「未配置密钥」
  └─ 已配置密钥
       → 组装指标 JSON
       → 调用模型（超时 30 秒）
            ├─ 调用失败或超时 → 模板兜底 → 标注「网络或服务异常」
            └─ 返回成功
                 → 数字回查
                      ├─ 通过 → 展示正文，元信息标注回查通过
                      └─ 未通过 → 自动重生成一次
                           ├─ 第二次通过 → 展示正文，标注已重新生成
                           └─ 第二次仍未通过 → 模板兜底 → 标注「数字校验未通过」
```

规则要点：

1. 无论走哪条路径，页面都必须产出可用的解读正文，不允许停在失败状态。
2. 元信息必须明确告知用户本次内容是否经过模型处理。
3. 降级不影响报告的其余部分。

### 3.4 导出链路

```
点击导出
  ├─ 口径有未应用修改 → 按钮禁用，不进入流程
  └─ 已应用
       → 生成 Word
       ├─ 生成 Excel
       ├─ 生成 PDF
       │    ├─ 检测到本机 Word 或 LibreOffice → 转换生成
       │    └─ 未检测到 → PDF 库直出
       └─ 汇总产物列表
            └─ 任一格式失败 → 该格式单独标记失败，其余保持成功
```

规则要点：

1. 三种格式相互独立，单个失败不影响其他格式。
2. 每次导出都使用当前最新的指标结果与 AI 解读。
3. 未生成 AI 解读时，导出使用模板文案，并在产物列表标注。

## 四、联动关系表

| 用户改动 | 直接重算 | 间接受影响 | 需要人工处理的后果 |
| --- | --- | --- | --- |
| 新增或删除文件 | 该文件解析 | 全部指标、图表、对比表 | AI 解读失效 |
| 修改列映射 | 该文件解析与判定 | 全部指标、图表 | AI 解读失效 |
| 修改当期限值 | 该周当期判定 | 当期口径指标、标准变化影响量 | AI 解读失效 |
| 应用口径配置 | 全部统一判定与指标 | 全部页面 | AI 解读清空，需重新生成 |
| 修改小样本阈值 | 无 | 标签与图注 | 无 |
| 修改异常分类词表 | 指标级异常与备注归类 | 帕累托图、明细归类 | AI 解读失效 |
| 人工编辑解读 | 无 | 报告正文 | 编辑后内容不再纳入数字回查 |

## 六、边界与异常场景清单

| 编号 | 场景 | 期望行为 |
| --- | --- | --- |
| E1 | 只上传 1 周数据 | P2 可进入，P3 显示空态提示；报告中不生成差异对比章节 |
| E2 | 某周有效记录为 0 | 该周不参与指标计算，图表显示断点，报告中标注该周无有效数据 |
| E3 | 全部记录合格 | 异常率 0%，帕累托图显示空态，报告中不生成异常明细表 |
| E4 | 全部记录异常 | 合格率 0%，Wilson 区间仍正常计算；报告中正常生成异常明细 |
| E5 | 判定列全部为空 | 一致率显示「不适用」，报告口径说明自动追加说明 |
| E6 | 外径下限等于上限 | 警告并允许继续，报告中标注限值为单点值 |
| E7 | 数值列含单位后缀 | 尝试提取数值并给出警告，无法提取的行进入问题清单 |
| E8 | 文件超过 10000 行 | 允许继续，给出性能警告 |
| E9 | 周次标签不连续 | 允许，按标签数值排序，报告按实际标签命名 |
| E10 | 备注含换行或超长文本 | 明细表截断显示，完整内容在记录详情面板与报告中完整呈现 |
| E11 | 同一箱/扎序号重复出现 | 计入重复记录警告，默认保留全部行参与计算 |
| E12 | 未生成 AI 解读直接导出 | 允许导出，执行摘要使用模板文案，产物列表标注 |
| E13 | 生成解读过程中切换口径 | 阻止切换，提示当前正在生成，需等待或取消 |
| E14 | 导出的章节勾选为 0 | 阻止并提示至少选择 1 个章节，报告头始终包含 |
| E15 | API 返回内容缺少小节标题 | 按返回格式异常处理，走模板兜底 |
